# Arquivo Rabenfels — assets faltantes

Pacote final em pixel art para a rota RPG. Todos os PNGs possuem fundo transparente real.

## Personagens

- `antoniette_vela_spritesheet.png` — folha 3×4, quatro direções, vela na mão direita.
- `antoniette_retrato_pixel.png` — retrato de diálogo, 1254×1254.
- `fenn_spritesheet_3x4.png` — folha 3×4 de Fenn.
- `dara_spritesheet_3x4.png` — folha 3×4 de Dara.

Ordem das folhas 3×4:

1. Linha 1: frente.
2. Linha 2: esquerda.
3. Linha 3: direita.
4. Linha 4: costas.

Cada linha contém passo com um pé, posição neutra e passo com o outro pé.
